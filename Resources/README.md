# Resources

## Dataset
- **Name:** Brain tumor dataset (Brain Tumor MRI Data)
- **Author / uploader:** tombackert (Kaggle)
- **Source:** Kaggle
- **Download link:** https://www.kaggle.com/datasets/tombackert/brain-tumor-mri-data
- **Licence / terms of use:** MIT
- **Date downloaded:** 2026/09/02
- **Size used in this project:** 5,600 training images (1,400 per class) and 1,600 test images (400 per class), 7,200 in total.
- **Classes:** glioma, meningioma, notumor, pituitary
- **Folder layout expected by the notebook:** `Training/<class>/` and `Testing/<class>/`. The dataset is not stored in this repository; download it from the link above (see `docs/INSTALLATION.md` in the team repo).
